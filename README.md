## MINI PAPAYA WEB EDITOR WITH LOGIN FUNCTION
- small version of my Papaya Web Editor
- only one user can login (username:mimi, password: nami)
- after that restyled version of my previous editor and resizable windows

## ABOUT MY PROJECT
- implementing login function for only one user with CommandLineRunner
- SQlite as Jpa function
- Easy to read structure and modular files
- simple to use and simple to modify

## REQUIREMENTS
- Java 21+
- IDE with Gradle
- TextEditor (HTML, CSS, Javascript)
